# Privacy Policy: CHC comments

Last updated: 21 November 2026

"CHC comments" is a private tool used only by the owner of the YouTube channel Church History Class (https://www.youtube.com/@ChurchHistoryClass) to read and reply to comments on that channel's own videos.

## What data it uses

Through the YouTube Data API, the tool reads public comments posted on Church History Class videos (comment text, the commenter's public display name and the comment date) and posts replies from the Church History Class channel.

## What it does not do

It does not collect, sell or share personal data with anyone. It does not sign in other users, show ads or track viewers. Comment data is used only to write a reply and is not stored beyond that.

## Google user data

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy (https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. Access can be removed at any time at https://myaccount.google.com/permissions. YouTube's own privacy policy is at https://policies.google.com/privacy.

## Contact

Questions can be sent through the Church History Class channel page on YouTube.
